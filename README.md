# Aveda Arenium

Scroll-driven story site for Aveda Arenium by DKG Landcorp (PR-7, GMADA Aerocity, Mohali).

Static site with no build step. Publish with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

- `index.html` — the whole page (styles and scripts inline)
- `f/` — scroll-film frames in AVIF (desktop single frames; `am00`-style files are phone sheets)
- `img/` — images, floor plans, logo and the two looping videos
